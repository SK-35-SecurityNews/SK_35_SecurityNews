ℹ️ 프로젝트 소개

CyberWatch는 rss_.py가 RSS로 수집해 MongoDB에 저장한 보안 뉴스를 키워드·유형·출처·월별 색인으로 검색하고 통계로 보여주는 대시보드입니다.

  • 백엔드 Flask (Python)
  • 데이터베이스 MongoDB {{ mongo_version }} · DB {{ db_name }}
  • 컬렉션 {% for c in collections %}{{ c }} {% endfor %}
  • 수집기 {{ rss_script }} {% if not rss_exists %}경로 없음{% endif %}

🧭 사용 방법

  • 홈 검색창에 키워드를 입력하거나 우측 색인(유형/출처/월별)을 클릭해 기사를 찾습니다.
  • 보안 뉴스 유형·출처별로 기사를 조회하고 제목을 눌러 원본으로 이동합니다.
  • 사이버범죄 통계 유형별 기사 수와 출처×유형 교차표를 봅니다.
  • 기간별 추이 최근 N일 동안 날짜별 기사 수를 유형별로 봅니다.
  • 데이터 원본 MongoDB 문서를 그대로 봅니다.
  • 데이터 새로고침 rss_.py의 수집 함수를 한 번 실행합니다.

🔌 검색 API

JSON 형식으로도 검색할 수 있습니다.

GET /api/search?q=랜섬웨어&category=&source=&month=2026-09
