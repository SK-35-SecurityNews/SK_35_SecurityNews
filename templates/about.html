ℹ️ 프로젝트 소개

CyberWatch는 보안 뉴스와 사이버범죄 통계를 MongoDB에 저장하고, 키워드·유형·출처·연도·태그 색인으로 검색할 수 있는 통합 대시보드입니다.

  • 백엔드 Flask (Python)
  • 데이터베이스 MongoDB {{ mongo_version }} · DB {{ db_name }}
  • 컬렉션 {% for c in collections %}{{ c }} {% endfor %}
  • 데이터 예시 데이터 (seed.py로 적재, 실제 통계가 아님)

🧭 사용 방법

  • 홈 검색창에 키워드를 입력하거나 우측 색인(유형/출처/연도/태그)을 클릭해 데이터를 찾습니다.
  • 보안 뉴스 news 컬렉션의 기사를 유형별로 조회합니다.
  • 사이버범죄 통계 연도를 선택해 유형별 발생건수와 비율을 확인합니다.
  • 연도별 추이 유형별 발생건수의 연도별 변화를 확인합니다.
  • 데이터 원본 MongoDB 각 컬렉션의 원본 문서를 그대로 봅니다.
  • 데이터 새로고침 상단 버튼을 누르면 예시 데이터를 다시 적재합니다.
