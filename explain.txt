 1. 구조
 Github
 - static/ : css, png 등 스타일 관련
 - templates/ : html(jinja2) 파일
 - venv/ 
 - app.py : main 함수 및 route 정의
 - README.md
 - requirements.txt
 - seed.py : db 연결 및 데이터 생성 +++(임의로 생성된 데이터, rss 연결 파일로 수정 및 코드 수정)+++

 2. app.py
 구조
 - /index : 대시보드 및 검색 파라미터로 색인
 - build_news_query() : DB에 직접적인 검색 함수; [카테고리, 출처, 년도]
 - /api/search : 웹페이지 api 검색
 - /news : 카테고리별로 페이지네이션
 - /stats : 사이버보안 통계 그래프로 시각화
 - /trend : 사이버보안 연도별 추이 선그래프 시각화
 - /data : mongodb의 데이터 원본 표기
 - /about : 홈페이지 소개

 3. templates
 html, css
 - base.html : 좌측의 사이드바 및 상단의 글자와 카드 구현, 부모 클래스로서 다른 html에 기능을 물려주며 block 형태로 다른 html을 채운다.
 - index.html : 검색부분 및 우측의 네비게이션
 - news.html : 뉴스 전문 나열
 - stats.html : 년도별 발생 건수 관련한 막대 그래프 (cloudflare(네트워크 보안 관련 회사이자 로드 벨런스, 캐시, 정보보안, 프록시 서버)의 cdn(컨텐츠 전송 서버 - 캐시) chart.js를 ajax로 로드)
 - trend.html : 전체 건수 관련한 선 그래프 (cloudflare의 cdn서버 chart.js를 ajax로 로드)
 - data.html : get 메소드로 파라미터로 받은 컬렉션를 나열
 - about.html : 서버 정보 및 사용방법
 - style.css
